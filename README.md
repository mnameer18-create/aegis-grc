# Aegis Intelligence v0.3 — Apple-inspired Compliance Demo

A self-contained, responsive, interactive **experience prototype** for Aegis Compliance Intelligence.

## Quick start

Open `index.html` in any modern desktop or mobile browser. No installation, external service, API key, or backend is needed.

## Features

- AI-first daily briefing, softly animated intelligence orb and glass-like floating navigation
- Ask Aegis with clearly simulated answers
- Regulatory Intelligence list and focused side-by-side Decision Studio
- Human review actions: confirm, request clarification, create remediation
- Gap & Action Management with open/close status
- Knowledge Library with manual reference registration
- Management summary and CSV export
- Decision History; browser-local saved demo state
- Additional Compliance workspaces previewed as future functionality
- Mobile responsive and reduced-motion accessibility support

## Critical limitations

- **No real AI, regulatory extraction, or BNM regulatory citation.** All sample documents are fictional.
- **No authentication, real file upload, encrypted backend, tenant isolation or secure audit trail.**
- Browser localStorage is used only for demo convenience; never enter sensitive or client information.
- Not for production, compliance decisions, or regulatory submissions.

## GitHub Pages

1. Create a dedicated public repository for the demo (do not publish production code/secrets).
2. Upload `index.html` and this `README.md` at repository root.
3. In Settings → Pages select Deploy from branch → `main` → `/ (root)`.
4. Share the Pages URL after testing in a private/incognito window.
